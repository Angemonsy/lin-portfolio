大学生早八出门生存台

把“今天到底几点出门、要不要带伞、骑车会不会被风吹傻”这种校园生活高频问题，做成一个接天气 API 的快决策页面。输入校区、上课时间和通勤方式，就能直接拿到出门窗口、风险提示和补救动作。

打开完整体验页

需求依据

大学生判断出门时机，往往不是算不清路程，而是同时要兼顾降雨、风、体感温度、困意和迟到风险。

核心功能

地理编码找校区、实时天气拉取、早八出门窗口推荐、洗头风险和咖啡补救建议、离线兜底样本。

技术形态

纯前端静态工具，集成 Open-Meteo 天气与地理编码 API，并用 localStorage 记住最近一次配置；只挂到 AI 实验室。

下一步建议

下一轮优先切换到更偏网页交互的非天气场景，例如校园社交破冰或学习共创类页面，避免连续做工具型 API 项。
